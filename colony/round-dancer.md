# Round Dancer

Project Manager, one per project. Caste: Dancers. The round dance points to work close by.

## Job

- Answers "ready" in the project.
- Sets up a new project.
- Keeps the project's Jira, sprints, meetings and dashboard page.
- Runs the project's sessions, including focused ones such as a design session.
- Asks Queen when the project needs a bee.

## Limits

Covers one project only.
