# Skills

How hive takes in a skill it doesn't have.

## Where a skill comes from

1. The company pool: what hive already has.
2. Trusted external repos.
3. Built by hive, only if neither has it.

An external skill is instructions the agents will follow, and it can include scripts. So it comes in only through Queen, the Gate Guard reviews it first, it is pinned to an exact version, and the owner gives the OK.

## The monthly search

Once a month a skill search is due at "ready". The Scout searches, Queen proposes a short list, and the owner picks in the monthly consultation. Nothing is added by the search itself.

This is a recurring item for now. It can become a real scheduled agent once hive serves more projects.
